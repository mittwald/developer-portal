## Summary


- The response property `/anyOf[#/components/schemas/de.mittwald.v1.marketplace.UnpublishedExtension]/context` became optional for the status `200` in the `GET` operation for the path `/v2/extensions/{extensionId}`. This is a breaking change.
- The request body became required for the `POST` operations for the paths `/v2/users/self/spotlights/{spotlightId}` and `/v2/users/self/spotlights/{spotlightId}/feedback`. This is a breaking change.
- Added the new optional 'header' request parameter `Accept-Language` for the `GET` operations for the paths `/v2/app-installations/{appInstallationId}/error-analysis`, `/v2/container-image-config`, and `/v2/stacks/{stackId}/services/{serviceId}/log-analysis`.
- Added the new optional request property `projectId` for the `POST` operation for the path `/v2/domain-transferable`.
- Added the required property `reasons/enabledIngressInOtherProject` to the response with the `200` status for the `POST` operation for the path `/v2/domain-transferable`.
- New endpoints were added for the `GET` operations for the paths `/v2/leaked-passwords/{passwordHashPrefix}` and `/v2/oauth2/clients/{oauthClientId}`.
- Removed the pattern `|^\+([0-9]{2,3}|1)-[0-9]{2,5}-[0-9]+$` from the request property `contact/phoneNumber` for the `POST` operation for the path `/v2/relocation`.
- Added the new optional request properties `x-description` and `x-update-schedule` for the `PATCH` operation for the path `/v2/stacks/{stackId}`.
- The request property `owner` became optional for the `POST` operation for the path `/v2/users/self/spotlights/{spotlightId}/feedback`.

## Client package releases


### mittwald PHP SDK v2.2.2 Release Summary

The mittwald PHP SDK has released version 2.2.2, which introduces new features, enhancements, and adjustments to improve user experience and functionality.

#### New Features
- **Leaked Password Verification**: A new endpoint has been added to check if a password has been compromised. By submitting a `passwordHashPrefix` (up to 5 characters), the API returns all matching password hashes with their prevalence counts, allowing applications to warn users about leaked credentials.

#### Enhancements
- **Domain Transferability Checks**: The domain transfer validation API has been enhanced to support project-specific contexts and prevent ingress conflicts. The request body now includes `projectId` to specify the target project, and the response includes `enabledIngressInOtherProject`, which indicates if an enabled ingress for the domain exists in another project.

#### Adjustments
- **Relocation Phone Number Validation**: The validation rules for the `phoneNumber` field in relocation requests have been relaxed by removing a strict regex constraint, allowing more flexible phone number formats.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.2).

### mittwald PHP SDK v2.2.1 Release Summary

The mittwald PHP SDK has been updated to version 2.2.1. This release introduces several new features and enhancements, particularly focusing on Marketplace OAuth2 client management, webhook execution resumption, and User spotlight tracking. Additionally, it includes improvements in extension listing capabilities and updates to request/response schemas for container service declarations.

#### Key Features and Enhancements:
- **Marketplace Enhancements**: 
  - New endpoint `contributorGetOauthClient` for detailed OAuth2 client information.
  - `extensionResumeWebhookExecutionForExtensionInstance` to resume suspended webhook executions.
  - New filtering option `contract.interactionRequired` for extension instances.

- **User Spotlight Management**:
  - `getSpotlightInfo` to fetch spotlight status and decision details.
  - `spotlightFeedback` for submitting user feedback and decisions.
  - `spotlightUsage` for recording usage metrics.

#### Deprecations:
- Stack properties `description` and `updateSchedule` are deprecated in favor of `x-description` and `x-update-schedule`.
- `restartPolicy` in service declarations is deprecated; use `restart` instead.
- The `owner` field in spotlight feedback and usage requests is deprecated.

#### API Behavior & Compatibility Updates:
- Clarification on declarative stack PUT endpoint behavior.
- The `context` field in `UnpublishedExtension` is now optional.

#### Documentation Updates:
- Updated docblocks and validation schemas.
- Added comprehensive request builders and response containers for new endpoints.

For more details, please refer to the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.1).
