## Client package releases


### mittwald PHP SDK v2.2.9 Release Summary

The mittwald PHP SDK has been updated to version 2.2.9. This release introduces several new features and enhancements:

- **AI Hosting Key Rotation**: New endpoints have been added to facilitate secure API key rotation for both customers and projects. This feature allows developers to issue new secrets while managing the transition period effectively.
- **Grace Period Support**: The key rotation operations now include an optional `gracePeriod` parameter, allowing the old secret to remain valid for a specified duration (e.g., `24h`, `1m`) alongside the new one before being revoked.
- **Enhanced Error Handling**: The SDK now generates comprehensive type-safe response classes to handle standard HTTP status codes (`400`, `403`, `404`, `429`) with structured error payloads.

**API Additions**:
- `AIHostingClient::customerRotateKey(CustomerRotateKeyRequest $request): CustomerRotateKeyOKResponse`
- `AIHostingClient::projectRotateKey(ProjectRotateKeyRequest $request): ProjectRotateKeyOKResponse`

**Generated Types**:
- New request and response classes have been added under the `CustomerRotateKey` and `ProjectRotateKey` namespaces. These include request builders with automatic URL construction, request body models with `gracePeriod` support, and dedicated response containers for success and error states, complete with validation and JSON serialization utilities.

For more details, please visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.9).
