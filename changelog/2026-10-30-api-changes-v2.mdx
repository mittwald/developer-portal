## Client package releases


### mittwald PHP SDK v2.2.20 Release Summary

The mittwald PHP SDK has been updated to version 2.2.20. This release includes several enhancements and clarifications across various components:

- **Container & Stack Networking**: Improved DNS resolution and isolation rules for containerized services. Managed applications within the same project can resolve services using `<serviceName>.<prefix>`, while containers within the same stack use the service name directly. Cross-stack communication is not supported to prevent unintended network exposure.

- **Volume Lifecycle & Management**: Updated behavior for stack configuration regarding volumes. Volumes omitted from a stack request are safely detached but not deleted, ensuring data preservation. Explicit deletion is required via the dedicated volume endpoint. The `orphaned` flag now clearly indicates that unmounted volumes retain their data until explicitly removed.

- **Service Configuration & Runtime Behavior**: 
  - Ports now support single ports, ranges, and protocols, but mapping ports to different numbers is unsupported.
  - Clarified the `unless-stopped` restart policy and noted that retry limits are accepted but ignored.
  - Enforced lowercase decimal units for memory byte values.
  - Container images are now resolved and locked to a specific digest at request time.

- **Stack Identifiers & Service States**: 
  - Added `unspecified` to the `ServiceStatus` enum.
  - Updated the `prefix` field in stack responses to emphasize its role as an immutable identifier.
  - Clarified the `shortId` field for SSH connections, noting that all API routes require the primary service `id`.

- **SDK Documentation & Generated Code Cleanup**: Comprehensive updates to PHPDoc comments and removal of redundant docblocks to align with the latest API specifications and improve the IDE experience.

For more details, please visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.20).

### mittwald PHP SDK v2.2.19 Release Summary

The mittwald PHP SDK has been updated to version 2.2.19. This release introduces new features, enhancements, and bug fixes to improve functionality and user experience.

#### New Features
- New endpoints for the AI Hosting API have been added, allowing developers to retrieve AI hosting keys and plans for authenticated users. These endpoints denormalize organization, project, and plan names, reducing the need for additional API calls.
- Added `userGetKeys` and `userGetPlans` methods to the AI Hosting client.
- Introduced comprehensive request and response models, along with `UserKey` and `UserPlan` schema definitions.

#### Enhancements & Bug Fixes
- **Contract API**: Improved error handling with explicit `403 Forbidden` responses for various contract endpoints.
- **Customer & Project APIs**: Enhanced error handling for membership updates, capturing status codes `400`, `403`, `404`, and `412`.
- **Container API**: Documentation updated to clarify `412 Precondition Failed` responses for pull-image webhooks when stacks are disabled or suspended.
- **Activitylog Schema**: Updated parameter property references in `BackupRestoreRequested`.

#### Code Generation Updates
- Removed `declare(strict_types=1);` from all generated client files to align with updated code generator configurations.

For more details, please visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.19).
