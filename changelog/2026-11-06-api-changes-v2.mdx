## Client package releases


### mittwald PHP SDK v2.2.23 Release Summary

The mittwald PHP SDK has been updated to version 2.2.23, introducing several new features and improvements. This release includes a dedicated endpoint for resetting notification settings, enhanced activity log tracing with credential identification, and staging flags for application models. Additionally, client-side error handling has been improved with typed response classes for various HTTP status codes, and schema namespaces have been updated to align with the Redirectus service.

#### New Features
- **Reset Notification Settings:** A new `notificationsResetNotificationSettings` endpoint in `NotificationClient` allows users to reset all notification channel settings to their defaults.
- **Activity Log Credential Tracking:** The `LogEntry` schema now includes a `credential` field to track the authentication method used for actions.
- **Application Staging Support:** The `App` schema now features a `stagingAllowed` property to indicate if staging `AppInstallation` instances can be created.

#### Improvements & Updates
- **Enhanced Error Handling:** Typed response classes for common HTTP status codes have been added to improve exception handling:
  - `GetUser`: Handles `400 Bad Request` and `401 Unauthorized` responses.
  - `Register`: Handles `403 Forbidden` responses.
  - `DnsCreateProjectDnsZone`: Handles `403 Forbidden` responses.
- **DNS Zone Creation Documentation:** Clarified documentation for creating DNS subzones.
- **Schema Namespace Migration:** The `Domain` and `EmailInbox` models have been moved to the `Redirectus` namespace.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.23).

### mittwald PHP SDK v2.2.22 Release Summary

The mittwald PHP SDK has been updated to version 2.2.22. This release introduces significant new features and enhancements to improve user authentication and application management.

#### Features Added
- **Passkey (WebAuthn) Support**: Comprehensive support for passkey lifecycle management, including endpoints for creating, authenticating, registering, challenging, confirming, and deleting passkeys.
- **Automatic App Updates**: A new `autoUpdatesActivated` boolean field in the `PatchAppinstallation` client allows for automatic version updates of app installations.

#### Enhancements
- **MFA & Authentication Flow**: 
  - The `multiFactorCode` is now optional in MFA and password change requests.
  - Added `passkeyCredential` support to `AuthenticateMfa` and `ChangePassword` requests.
  - Updated `AuthenticateAcceptedResponse` to include `availableSecondFactors` and `passkeyChallenge` for dynamic MFA method discovery.
- **HTTP Status Handling**: Introduced dedicated `403 Forbidden` response classes for operations such as `GetAppinstallation`, `GetCronjob`, `GetMysqlDatabase`, and `GetRedisDatabase`.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.22).

### mittwald PHP SDK v2.2.21 Release Summary

The mittwald PHP SDK has been updated to version v2.2.21. This release includes several bug fixes, improvements, and new features. 

#### Bug Fixes & Improvements
- Enhanced handling for HTTP 403 (Forbidden) status codes in the Customer and Project client modules.
- Updated `CustomerClientImpl` and `ProjectClientImpl` to map 403 responses to new `ForbiddenResponse` classes for specific endpoints, improving error handling clarity.

#### New Features
- **Ingress Access Protection Configuration**: 
  - Added schema support for configuring Ingress access protection, allowing detailed control over authentication and authorization.
  - Introduced support for `mStudio` and external `OpenID Connect (OIDC)` authentication providers.
  - Implemented `PathAccessProtection` and `AllPathsAccessProtection` models for defining protection scope.
  - Added `AccessProtectionRules` for setting access policies based on email addresses, domains, project memberships, and authenticated user access.
  - Extended the `Ingress` model with the `accessProtection` property to support these configurations.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.21).
