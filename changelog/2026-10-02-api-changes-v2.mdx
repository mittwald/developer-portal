## Client package releases


### mittwald PHP SDK v2.2.4 Release Summary

The mittwald PHP SDK has released version 2.2.4, which introduces a comprehensive set of auto-generated PHP schema classes for the V2 API Client's Activity Log, focusing on **Cronjob** event tracking. These new models provide strict type-safe representations for lifecycle events and configuration modifications, allowing developers to accurately parse, validate, and serialize activity log payloads with built-in JSON Schema validation and immutable state management.

#### Key Additions:
- **Cronjob Lifecycle & Execution Events**: New classes such as `CronjobCreated`, `CronjobDeleted`, and `CronjobExecution` have been added to track lifecycle and execution events.
- **Cronjob Configuration Update Events**: Classes like `CronjobActiveUpdated` and `CronjobCommandUpdated` have been introduced to handle configuration updates.
- **Supporting & Validation Types**: Includes `*ChangesAfter` and `*ChangesBefore` classes for tracking state differences, enumerations for standardized event naming, and built-in methods for serialization/deserialization.

These classes are auto-generated by the `mittwald/api-client-builder` package, featuring strict type declarations and immutable state management.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.4).

### mittwald PHP SDK v2.2.3 Release Summary

The mittwald PHP SDK has been updated to version 2.2.3, introducing significant enhancements and new features. This release focuses on improving DNS zone file management and DNS zone creation for verified Ingresses.

#### Key Features:

- **DNS Zone File Import Support**: 
  - New endpoints for importing DNS zone files with validation, preview, and job tracking capabilities.
  - Endpoints include `dnsCreateDnsZoneFileImport`, `dnsGetDnsZoneFileImport`, and `dnsListDnsZoneFileImports`.
  - New models and schemas such as `CreateZoneFileImportResponse`, `ZoneFileImport`, and `ZoneImportPreview` are introduced.

- **DNS Zone Creation for Verified Ingress**:
  - New endpoint `dnsCreateProjectDnsZone` for creating DNS zones within a project for verified Ingresses, determining root or subzone provisioning automatically.

#### Deprecation Notice:

- The `DnsCreateDnsZone` operation is deprecated, replaced by `DnsCreateProjectDnsZone` and `DnsCreateDnsZoneFileImport`.

#### Schema & Documentation Updates:

- An optional `description` field added to the App Schema for localized descriptions.
- Documentation updates for `MailClient` and `UserClient` to reflect changes in asynchronous workflows.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.3).
