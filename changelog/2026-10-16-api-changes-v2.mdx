## Client package releases


### mittwald PHP SDK v2.2.14 Release Summary

The mittwald PHP SDK has released version 2.2.14, which includes several new features, deprecations, and updates. This release focuses on improving error handling, enhancing status tracking, and implementing important security updates.

#### Features
- **Improved Error Handling**: Introduced support for handling HTTP 413 (Request Entity Too Large) responses during file operations with the new `CreateFileRequestEntityTooLargeResponse` class.
- **Status Tracking for Plans**: Added a `suspended` boolean field to `CustomerPlan` and `ProjectPlan` schemas to track suspension status, including validation and JSON serialization/deserialization support.

#### Deprecations
- **AI Hosting API Key Exposure**: The `key` field in the `AIHosting/Key` schema is now deprecated. Future responses will not expose the secret API key, and clients should prepare to transition away from using this field.

#### Updates
- Enhanced the `FileClientImpl` to route 413 status codes to the new error response handler.
- Improved validation and serialization logic for AI Hosting schema models.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.14).

### mittwald PHP SDK v2.2.13 Release Summary

The mittwald PHP SDK has been updated to version 2.2.13. This release introduces new features and updates to enhance domain transferability checks and network visibility for servers and projects. 

#### Features
- **Domain Transferability Premium Flag**: A new `premiumDomain` boolean field has been added to domain transfer checks. This flag indicates when a registry charges a premium price for transferring a domain. Note that premium domains are not currently supported for transfer operations.
- **Primary IP Address Tracking**: The `primaryIpAddresses` attribute has been added to the `Project`, `ProjectListItem`, and `Server` models. This feature provides access to the primary public IPv4 and IPv6 addresses, facilitating easier network configuration.

#### API & Client Updates
- The `CheckDomainTransferability` response classes have been updated to include logic for the `premiumDomain` property.
- A new `PrimaryIpAddresses` schema class has been introduced, featuring nullable `v4` and `v6` string properties with JSON schema validation.
- The `primaryIpAddresses` feature has been integrated into relevant models, with corresponding methods for manipulation and serialization.

For more details, visit the [release page](https://github.com/mittwald/api-client-php/releases/tag/v2.2.13).

### mittwald PHP SDK Release v2.2.12

The latest release of the mittwald PHP SDK, [v2.2.12](https://github.com/mittwald/api-client-php/releases/tag/v2.2.12), introduces enhancements to the activity log schema, focusing on comprehensive tracking for SSH and SFTP user operations. This update includes new event types to capture the lifecycle of SSH/SFTP users, such as creation, modification, and deletion, along with detailed `before`/`after` state snapshots for audit purposes.

#### New Activity Log Events

The release supports the following new SSH/SFTP user activity log events:

- **`SshUserCreated`**: Logs the creation of new SSH users.
- **`SftpUserCreated`**: Logs the creation of new SFTP users.
- **`SshUserDeleted`**: Tracks the deletion or expiration of SSH/SFTP users.
- **`SshUserActiveUpdated`**: Monitors changes to the active/inactive status of users.
- **`SshUserDescriptionUpdated`**: Captures updates to user descriptions.
- **`SshUserPasswordUpdated`**: Logs password configuration changes.
- **`SshUserPublicKeysUpdated`**: Tracks updates to user public keys.
- **`SshUserExpiryUpdated`**: Monitors changes to user expiration dates.
- **`SftpUserAccessLevelUpdated`**: Tracks modifications to SFTP user access levels (e.g., `read` vs `full`).
- **`SftpUserDirectoriesUpdated`**: Records updates to SFTP user directory mappings.

These updates are seamlessly integrated with the existing `LogEntry` structure to enhance detailed activity monitoring.
