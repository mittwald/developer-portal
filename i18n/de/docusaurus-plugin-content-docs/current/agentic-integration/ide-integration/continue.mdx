# Continue mit mittwald verwenden

[Continue](https://www.continue.dev) ist ein Open-Source KI-Code-Assistent für JetBrains IDEs und Visual Studio Code.

## Installation

Installiere das Continue-Plugin:

- **JetBrains IDEs**: [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/22707-continue)
- **Visual Studio Code**: [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Continue.continue)

## Konfiguration

Continue wird über eine `config.yaml` konfiguriert, typischerweise unter `~/.continue/`.

### Basis-Konfiguration

Lege mittwald als Model Provider an:

```yaml
name: mittwald
version: 1.0.0
schema: v1
models:
  - name: DeepSeek-V4.1-Flash-1017
    provider: openai
    model: DeepSeek-V4.1-Flash-1017
    apiBase: https://llm.aihosting.mittwald.de/v1
    apiKey: sk-your-api-key-here
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use
      - image_input
    defaultCompletionOptions:
      contextLength: 1048576
      maxTokens: 32768
      temperature: 1.0
      topP: 1.0
  - name: Kolibri-1
    provider: openai
    model: Kolibri-1
    apiBase: https://llm.aihosting.mittwald.de/v1
    apiKey: sk-your-api-key-here
    roles:
      - chat
    defaultCompletionOptions:
      contextLength: 1048576
      maxTokens: 32768
      temperature: 1.0
      topP: 0.97
      topK: 128
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

Ersetze `sk-your-api-key-here` durch deinen mittwald AI-Hosting-API-Key ([so bekommst du einen](/docs/v2/platform/aihosting/access-and-usage/access)).

Die Konfiguration legt zwei Modelle an:

- **DeepSeek-V4.1-Flash-1017** für Chat, Edits und den Agent-Modus. Es liest Bilder und denkt
  nach, bevor es antwortet, deshalb lässt `maxTokens` Platz für das Reasoning. Bricht eine
  Antwort ab, bevor das Modell etwas schreibt, erhöhe `maxTokens`.
- **Kolibri-1** für Chat auf Deutsch. Es liest nur Text und ruft Tools nur mit
  `tool_choice: "auto"` auf, deshalb fehlt `tool_use` in der Konfiguration. Im Agent-Modus
  nutzt du DeepSeek-V4.1-Flash-1017.

Beide Modelle sind in der [Testphase](/docs/v2/platform/aihosting/access-and-usage/lifecycle#testphase). Für den Produktivbetrieb wähle stattdessen
`Qwen3.8-27B-NVFP4` (Stable) mit `contextLength: 256000`.

## MCP Server Integration {#mcp}

Continue unterstützt Model Context Protocol Server für erweiterte Fähigkeiten. Ergänze MCP-Server in deiner `config.yaml`:

```yaml
mcpServers:
  # Context7: Aktuelle Library-Dokumentation
  context7:
    name: Context7
    command: npx
    args: ["-y", "@upstash/context7-mcp"]
    env: { CONTEXT7_API_KEY: "your-context7-api-key" }

  # Brave Search: Websuche mit Fokus auf Privatsphäre
  brave-search:
    name: Brave
    command: npx
    args: ["-y", "@brave/brave-search-mcp-server"]
    env: { BRAVE_API_KEY: "your-brave-api-key" }

  # Directus: Datenverwaltung für Headless-CMS
  directus:
    name: Directus
    command: npx
    args: ["-y", "@directus/content-mcp", "--stdio"]
    env:
      DIRECTUS_URL: "https://your-directus-instance.com"
      DIRECTUS_TOKEN: "your-directus-token"

  # OpenSearch: Such- und Analytics-Engine
  opensearch:
    name: OpenSearch
    command: uvx
    args: ["opensearch-mcp-server-py"]
    env:
      OPENSEARCH_URL: "https://localhost:9200"
      OPENSEARCH_USERNAME: "your-opensearch-username"
      OPENSEARCH_PASSWORD: "your-opensearch-password"

  # TYPO3: CMS-Content- und Backend-Verwaltung (erfordert mittwald CLI)
  typo3:
    name: TYPO3
    command: mw
    args:
      [
        "app",
        "exec",
        "--quiet",
        "--installation-id=a-XXXXX",
        "vendor/bin/typo3 mcp:server",
      ]

  # mittwald MCP: Infrastrukturverwaltung
  mittwald:
    name: mittwald
    transport:
      type: sse
      url: https://mcp.mittwald.de/mcp
```

### MCP-Tools nutzen

Bitte den Assistenten explizit um Tool-Nutzung, z. B.:

- "Use Brave Search to find recent information about React 19..."
- "Query OpenSearch for recent error logs..."
- "Use mittwald MCP to list my projects"

Begrenze den Zugriff immer eng und prüfe jeden Datenzugriff und jede Änderung.

## Best Practices

### Sicherheit mit MCP-Servern

- Zugriff strikt begrenzen (Datenbanken, Domains, Pfade)
- Tool-Aufrufe für Audits protokollieren
- Für Tool-Planung niedrige Temperatur verwenden (`<= 0.2`), um Halluzinationen zu reduzieren.
  Reasoning-Modelle wie DeepSeek-V4.1-Flash-1017 sind die Ausnahme: Behalte die
  Sampling-Parameter von ihren Modellseiten bei
- Diffs und Queries vor Ausführung prüfen
- Wenn möglich read-only beginnen
