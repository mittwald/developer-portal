# Kilo Code mit mittwald

Kilo Code ist eine Visual Studio Code Extension für KI-gestützte Entwicklungsunterstützung mit OpenAI-kompatiblen Providern.

## Installation

Installiere Kilo Code über den [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

## Konfiguration

Konfiguriere Kilo Code mit den KI-Modellen von mittwald:

1. Kilo-Code-Einstellungen in VS Code öffnen (Zahnrad-Symbol) und zum Tab **Providers** wechseln
2. Unten in der Liste auf **Custom provider** klicken
3. Den Dialog ausfüllen:
   - **Provider ID** und **Display name**: `mittwald`
   - **Provider API**: OpenAI Compatible
   - **Base URL**: `https://llm.aihosting.mittwald.de/v1`
   - **API key**: Dein mittwald AI-Hosting-API-Key ([so bekommst du einen](/docs/v2/platform/aihosting/access-and-usage/access))
   - **Models**: `DeepSeek-V4.1-Flash-1017`
4. Auf **Submit** klicken

DeepSeek-V4.1-Flash-1017 hat ein Kontextfenster von 1.048.576 Token, liest Bilder und denkt
nach, bevor es antwortet. Token-Limits und Bild-Input stellst du in der Konfigurationsdatei
`kilo.jsonc` ein, siehe die [Anleitung von Kilo Code zu Custom Models](https://kilo.ai/docs/code-with-ai/agents/custom-models). Setz das
Kontext-Limit auf `1048576`, das Output-Limit auf mindestens `32768` und ergänze `image` bei
den Input-Modalitäten.

Das Modell ist in der [Testphase](/docs/v2/platform/aihosting/access-and-usage/lifecycle#testphase). Für den Produktivbetrieb wähle stattdessen
`Qwen3.8-27B-NVFP4` (Stable) mit einem Kontext-Limit von `256000`.

### Umgebungsvariablen

Alternativ lokal per Umgebungsvariablen:

```shellsession
user@local $ export OPENAI_API_KEY=sk-your-api-key-here
user@local $ export OPENAI_BASE_URL=https://llm.aihosting.mittwald.de/v1
```

Wähl danach das Modell in der Modellauswahl von Kilo Code für Agent-Aufgaben aus.

## MCP Server Integration {#mcp}

Kilo Code unterstützt MCP-Server per UI (Tools → Add MCP Server) oder Konfigurationsdatei:

```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"],
      "env": { "CONTEXT7_API_KEY": "your-key" }
    },
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@brave/brave-search-mcp-server"],
      "env": { "BRAVE_API_KEY": "your-key" }
    },
    "directus": {
      "command": "npx",
      "args": ["-y", "@directus/content-mcp", "--stdio"],
      "env": {
        "DIRECTUS_URL": "https://your-directus-instance.com",
        "DIRECTUS_TOKEN": "your-directus-token"
      }
    },
    "opensearch": {
      "command": "uvx",
      "args": ["opensearch-mcp-server-py"],
      "env": {
        "OPENSEARCH_URL": "https://localhost:9200",
        "OPENSEARCH_USERNAME": "your-opensearch-username",
        "OPENSEARCH_PASSWORD": "your-opensearch-password"
      }
    },
    "typo3": {
      "command": "mw",
      "args": [
        "app",
        "exec",
        "--quiet",
        "--installation-id=a-XXXXX",
        "vendor/bin/typo3 mcp:server"
      ]
    },
    "mittwald": {
      "transport": {
        "type": "sse",
        "url": "https://mcp.mittwald.de/mcp"
      }
    }
  }
}
```

### Web Fetching

Kilo Code kann Web-Fetch- und Browsing-Tools nutzen, um externe Seiten abzurufen und
zusammenzufassen:

**Best Practices:**

- Öffentliche URLs bevorzugen (ohne Login)
- Genaue Ziel-Links im Prompt angeben
- Netzwerk-Scope klein halten
- Den Agent bitten, zu jeder Aussage die Quell-URL anzugeben
- Für Faktenextraktion deterministisch samplen: `temperature <= 0.2`

**Beispiel-Prompts:**

- "Fetch https://example.com/spec and summarize key endpoints in 10 bullet points. Include canonical links."
- "Open https://huggingface.co/model-page and extract context length, modalities, and license. Return as JSON."
