# Zed mit mittwald

[Zed](https://zed.dev) ist ein performanter Code-Editor mit integrierten KI-Funktionen und OpenAI-kompatiblen Endpoints.

## Voraussetzungen

- Zed Editor installiert
- mittwald AI-Hosting-API-Key ([so bekommst du einen](/docs/v2/platform/aihosting/access-and-usage/access))

## Konfiguration

### Über die UI

1. Agent-Panel-Einstellungen öffnen (`agent: open settings`)
2. Unter "LLM Providers" auf **Add Provider** klicken
3. "OpenAI API Compatible" wählen
4. Konfigurieren:
   - **Provider name**: `mittwald`
   - **API URL**: `https://llm.aihosting.mittwald.de/v1`
   - **API Key**: dein mittwald AI-Hosting-API-Key
   - **Model**: `DeepSeek-V4.1-Flash-1017`
   - **Context window**: `1048576`

### Über settings.json

Alternativ konfigurierst du Zed über `settings.json`:

```json
{
  "language_models": {
    "openai_compatible": {
      "mittwald": {
        "api_url": "https://llm.aihosting.mittwald.de/v1",
        "available_models": [
          {
            "name": "DeepSeek-V4.1-Flash-1017",
            "display_name": "DeepSeek-V4.1-Flash-1017",
            "max_tokens": 1048576,
            "max_output_tokens": 32768,
            "capabilities": {
              "tools": true,
              "images": true,
              "parallel_tool_calls": false,
              "prompt_cache_key": false
            }
          }
        ]
      }
    }
  }
}
```

`max_output_tokens` lässt Platz für das Reasoning, das DeepSeek-V4.1-Flash-1017 vor der
Antwort schreibt, und mit `images` kannst du Screenshots anhängen. Das Modell ist in der
[Testphase](/docs/v2/platform/aihosting/access-and-usage/lifecycle#testphase). Für den Produktivbetrieb trag stattdessen `Qwen3.8-27B-NVFP4` (Stable) mit
`"max_tokens": 256000` ein.

:::note

Leg API-Keys nicht in `settings.json` ab. Gib den Key in der UI ein oder setze ihn als
Umgebungsvariable, die nach der Provider-ID benannt ist:

```shellsession
user@local $ export MITTWALD_API_KEY=sk-your-api-key-here
```

:::

## Nutzung

Nach der Konfiguration kannst du mittwald KI-Modelle im Agent Panel nutzen für:

- Code-Generierung und Completion
- Refactoring und Optimierung
- Dokumentation und Erklärungen
- Code-Review und Verbesserungsvorschläge
