# Zed mit mittwald

[Zed](https://zed.dev) ist ein performanter Code-Editor mit integrierten KI-Funktionen und OpenAI-kompatiblen Endpoints.

## Voraussetzungen

- Zed Editor installiert
- mittwald AI-Hosting-API-Key ([so bekommst du einen](/docs/v2/platform/aihosting/access-and-usage/access))

## Konfiguration

### Über die UI

1. Agent-Panel-Einstellungen öffnen (`agent: open settings`)
2. Unter "LLM Providers" auf **Add Provider** klicken
3. "OpenAI API Compatible" wählen
4. Konfigurieren:
   - **Provider name**: `mittwald`
   - **API URL**: `https://llm.aihosting.mittwald.de/v1`
   - **Model**: `Qwen3.5-122B-A10B-FP8`

### Über settings.json

```json
{
  "language_models": {
    "openai_compatible": {
      "mittwald": {
        "api_url": "https://llm.aihosting.mittwald.de/v1",
        "available_models": [
          {
            "name": "Qwen3.5-122B-A10B-FP8",
            "display_name": "Qwen3.5-122B-A10B-FP8",
            "max_tokens": 245760
          }
        ]
      }
    }
  }
}
```

**Hinweis:** Zed speichert API-Keys nicht in `settings.json`. Setze den Key als Umgebungsvariable:

```shellsession
user@local $ export MITTWALD_API_KEY=<dein-api-key>
```

## Nutzung

Nach der Konfiguration kannst du mittwald KI-Modelle im Agent Panel nutzen für:

- Code-Generierung und Completion
- Refactoring und Optimierung
- Dokumentation und Erklärungen
- Code-Review und Verbesserungsvorschläge
