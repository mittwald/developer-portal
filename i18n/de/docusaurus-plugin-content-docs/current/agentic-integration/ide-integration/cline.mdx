# Cline mit mittwald

[Cline](https://cline.bot) ist ein KI-Coding-Assistent für Visual Studio Code, Cursor und Windsurf.

## Installation

Installiere die Cline-Erweiterung für deine IDE:

- [Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev)
- Cursor (nutzt VS Code Marketplace)
- Windsurf (nutzt VS Code Marketplace)

## Konfiguration

Konfiguriere Cline über die UI:

1. Cline-Einstellungen öffnen
2. **API Provider**: "OpenAI Compatible"
3. **Base URL**: `https://llm.aihosting.mittwald.de/v1`
4. **OpenAI Compatible API Key**: Dein mittwald AI-Hosting-API-Key ([so bekommst du einen](/docs/v2/platform/aihosting/access-and-usage/access))
5. **Model ID**: `DeepSeek-V4.1-Flash-1017`
6. Unter **Model Configuration** Bild-Support aktivieren, **Context Window Size** auf
   `1048576` und **Max Output Tokens** auf `32768` setzen

DeepSeek-V4.1-Flash-1017 denkt nach, bevor es antwortet. Bricht eine Antwort ab, bevor das
Modell etwas schreibt, erhöhe **Max Output Tokens**. Das Modell ist in der
[Testphase](/docs/v2/platform/aihosting/access-and-usage/lifecycle#testphase). Für den Produktivbetrieb wähle stattdessen `Qwen3.8-27B-NVFP4`
(Stable), mit einem Kontextfenster von `256000` und aktiviertem Bild-Support.

## Features

Cline unterstützt:

- Autonomes Coding und Refactoring
- Datei-Bearbeitung und -Erstellung
- Terminal-Befehle ausführen
- Web-Browsing (bei passender Konfiguration)
- Tool Use und agentic Workflows
