title: Gaining access
---

To use mittwald's AI hosting, you need an API key. First, you need access to the [mStudio](https://studio.mittwald.de) and an [organization](https://studio.mittwald.de/app/organizations). Both can be created free of charge. You don't need a hosting product. You can then order the "AI-Hosting" product from the "Organization" or "Project" menu, where you also find the available plans and which one fits your needs.

Once the booking is complete, you can create an API key to access the models.
