title: Gaining access
---

To use mittwald's AI hosting, you need to obtain an API key. First, you need access to the [mStudio](https://studio.mittwald.de) and an [organization](https://studio.mittwald.de/app/organizations). Both can be created free of charge. You can then order the "AI-Hosting" product via the "Organization" or "Project" menu items. There, you will also find information about the available plans and which one is right for you.

Afterwards, you can create an API key.
